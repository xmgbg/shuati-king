# 刷题KING

<img src="assets/logo.png" alt="刷题KING LOGO" width="160" />

刷题KING是一款规划中的 Windows 桌面刷题软件。目标是让用户从 PDF、Word 或文本资料建立知识库，生成题目，并进行日常练习和模拟考试。

## 计划功能

- 导入 PDF、Word 和文本资料，整理为知识库
- 根据资料生成选择题、填空题
- 日常刷题与模拟考试
- 查看答题结果

## 计划使用流程

导入资料 → 检查资料内容 → 生成并审核题目 → 刷题或模拟考试 → 查看结果

> 项目处于需求规划阶段。具体功能范围、出题方式和技术方案尚未最终确定，当前没有可下载的程序。
